# UI Layout & Navigation Guidelines

1. **Minimal Navigation Bar**:
   - Keep the primary navigation bar minimal and uncluttered.
   - Do not add sub-feature or secondary tool links (e.g., "Timing Adjuster", "Viral Styles", "Burn Subtitles") to the navbar if the primary homepage studio/app already unifies those workflows.
   - Limit navbar links to essential informational pages (e.g., "How It Works", "About") alongside the theme toggle, language switcher, and primary CTA.

2. **Unified Single-Page Experience**:
   - Prefer a streamlined, compact homepage layout.
   - When introducing multiple workflows (e.g., AI auto-captioning vs. burning existing subtitle files), use clean tabs/mode switchers within the core interactive dropzone/studio rather than fragmenting into repetitive standalone pages with duplicate functionality.

3. **High Contrast & Theme Invariance**:
   - Ensure all interactive tabs, pills, and dropzone buttons have high-contrast text and crisp active states in both Light and Dark themes.
